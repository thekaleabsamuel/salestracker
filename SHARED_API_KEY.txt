# 🔑 API Key for Team Use

## For Team Lead:

1. Open `server/.env` 
2. Find the line: `GOOGLE_PLACES_API_KEY=YOUR_API_KEY_HERE`
3. Replace `YOUR_API_KEY_HERE` with your actual API key
4. Save the file
5. Commit and push - the `.env` file will be included in the repo (private repo)
